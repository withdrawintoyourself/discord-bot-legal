Политика конфиденциальности

Как частный Discord-бот использует данные, необходимые для его работы.

  1. Общая информация

    Бот является частным проектом, созданным для использования на личном Discord-сервере.

  2. Обработка данных

    Для выполнения своих функций бот может обрабатывать идентификаторы пользователей, серверов, каналов и информацию о выполненных командах.

  3. Цель обработки

    Полученные данные используются исключительно для обеспечения работоспособности бота и выполнения пользовательских команд.

  4. Личная информация

    Бот не предназначен для сбора паролей, платёжной информации или других конфиденциальных сведений пользователей.

  5. Хранение данных

    Данные могут временно обрабатываться или сохраняться в объёме, необходимом для работы функций бота.

  6. Передача третьим лицам

    Данные пользователей не продаются и не передаются рекламодателям. Для работы бота может использоваться инфраструктура Discord.

  7. Безопасность

    Владелец принимает разумные меры для защиты информации от несанкционированного доступа.

  8. Удаление данных

    Участники сервера могут обратиться к владельцу с запросом на удаление сохранённой информации, связанной с их аккаунтом.

  9. Ограничение доступа

    Использование бота ограничено участниками частного Discord-сервера.

  10. Обновление политики

    Политика конфиденциальности может изменяться при обновлении функциональности бота или способов обработки данных.
